PUI89 · ความปลอดภัยและความน่าเชื่อถือ

ออกแบบโดยคำนึงถึงความปลอดภัย ตรวจสอบด้วยหลักฐาน

แนวทางพื้นฐานสำหรับเว็บไซต์ PUI89 และคลังโครงการทั้ง 7 โครงการ ช่วยลดความเสี่ยง แต่ไม่สามารถรับประกันว่าจะไม่มีการโจมตีหรือมัลแวร์

ความเสี่ยงที่ให้ความสำคัญ

  • การแก้ไขเว็บไซต์หรือคลังโครงการโดยไม่ได้รับอนุญาต
  • แพ็กเกจอันตราย การยึด workflow และการดาวน์โหลดไฟล์ที่ไม่ปลอดภัย
  • รหัสผ่าน โทเคน หรือข้อมูลลับรั่วไหล
  • มัลแวร์ ไฟล์ถูกแก้ไข และการโจมตีห่วงโซ่อุปทานซอฟต์แวร์
  • ข้อมูลนำเข้าและผลลัพธ์ AI ที่ไม่น่าเชื่อถือหรือข้ามขอบเขตความปลอดภัย

มาตรการพื้นฐาน

  • ใช้ Pull Request และป้องกัน branch หลักตามความสามารถของการตั้งค่าคลัง
  • จำกัดสิทธิ์ GitHub Actions เท่าที่จำเป็น และไม่เปิดเผย secrets ให้โค้ดจาก Pull Request ที่ไม่น่าเชื่อถือ
  • ตรวจสอบแหล่งที่มา ใบอนุญาต และความเสี่ยงของ dependencies, actions และโมเดลก่อนนำมาใช้
  • ตรวจสอบชนิดและขนาดไฟล์ แหล่งที่มา hash และจัดการข้อผิดพลาดอย่างปลอดภัย
  • การตัดสินใจสำคัญต้องมีมนุษย์กำกับ AI ไม่มีสิทธิ์สั่งงานฮาร์ดแวร์โดยอัตโนมัติ
  • เก็บ revision ที่เชื่อถือได้และมีขั้นตอนกู้คืนเมื่อเกิดเหตุ

แจ้งช่องโหว่อย่างเป็นส่วนตัว

อย่าเผยแพร่รายละเอียดการโจมตี รหัสผ่าน โทเคน ข้อมูลส่วนบุคคล หรือข้อมูลอ่อนไหวใน issue สาธารณะ ให้ใช้ระบบ Private Vulnerability Reporting ของ GitHub หากเปิดใช้งาน หรือ ติดต่อผู้ดูแลผ่าน GitHub ทางการของ PUI89 โดยแจ้งคลัง/ไฟล์/commit ผลกระทบ และวิธีทดสอบที่ปลอดภัย
