01 · EXPERTISE

ความเชี่ยวชาญและคำแนะนำ

AI, Computer Vision, Embedded Software, อิเล็กทรอนิกส์ วิศวกรรมเครื่องกล หุ่นยนต์ การออกแบบผลิตภัณฑ์ ความปลอดภัย และการตรวจสอบโค้ดโดยผู้เชี่ยวชาญ

02 · HARDWARE

อุปกรณ์และสถานที่ทดสอบ

กล้อง เซนเซอร์ Edge Computer บอร์ดพัฒนา แพลตฟอร์มหุ่นยนต์ เครื่องมือวัด และโอกาสเข้าถึงสถานที่ทดสอบภายใต้เงื่อนไขที่เหมาะสม

03 · COMPONENTS

วัสดุและชิ้นส่วน

อุปกรณ์อิเล็กทรอนิกส์ มอเตอร์ แบตเตอรี่ ตัวควบคุม ชิ้นส่วนกลไก วัสดุผลิตชิ้นงาน และอุปกรณ์สำหรับสร้างต้นแบบ โดยต้องตรวจสอบความเข้ากันได้และความปลอดภัยก่อน

04 · RESEARCH

งานวิจัย ข้อมูล และความร่วมมือ

ชุดข้อมูลที่มีสิทธิ์ใช้งานชัดเจน โอกาสทำวิจัย การทดสอบอิสระ ความร่วมมือกับมหาวิทยาลัยหรือภาคอุตสาหกรรม และการมีส่วนร่วมใน Open Source

การสนับสนุนด้านทุนหรือสิ่งของเป็นเพียงหนึ่งในหลายรูปแบบ ไม่ใช่ข้อกำหนด โปรดตกลงขอบเขต ความเป็นเจ้าของ ค่าใช้จ่าย การส่งมอบ และเงื่อนไขต่าง ๆ ก่อนส่งเงิน อุปกรณ์ หรือวัสดุ และโปรดอย่าจัดส่งสิ่งของก่อนตกลงรายละเอียดร่วมกัน

2. ความร่วมมือ

เปิดรับความร่วมมือด้านการวิจัย AI และหุ่นยนต์ การให้คำปรึกษาทางเทคนิค การตรวจสอบโค้ด การทดสอบอิสระ การพัฒนา Open Source และการแลกเปลี่ยนความรู้กับบุคคล มหาวิทยาลัย ห้องปฏิบัติการ และองค์กร

การพูดคุยหรือส่งข้อเสนอไม่ได้หมายความว่ามีทุน ผู้สนับสนุน หรือความร่วมมือได้รับการยืนยันแล้ว

  • ช่องทางทางการ: เว็บไซต์ PUI89 และ GitHub
  • อย่าเปิดเผยรหัสผ่าน, OTP, recovery code, private key หรือ API token ให้ผู้ที่อ้างตัวว่าเป็นตัวแทน PUI89
  • ตรวจสอบผู้ส่งและองค์กรผ่านช่องทางอิสระ ระวังข้อเสนอทุนหรือการลงทุนที่รับประกันผลและเรียกเก็บเงินล่วงหน้า
  • ตกลงขอบเขต ค่าใช้จ่าย สิทธิในข้อมูลและทรัพย์สินทางปัญญา และเงื่อนไขการทำงานเป็นลายลักษณ์อักษรก่อนเริ่มงาน
  • อย่าเผยแพร่ข้อมูลส่วนบุคคล ชุดข้อมูลที่มีข้อจำกัด หรือข้อมูลลับในพื้นที่สาธารณะ
