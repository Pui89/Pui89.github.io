# PUI89 AI Robot Car — SHIELD Starter

**Repository status:** not created in the connected GitHub account at the time this starter was prepared.

## Research-first scope
Advanced intelligent vehicle software: road perception, sensor integrity, driver assistance, hazard prediction, navigation research, vehicle health monitoring and explainable warnings.

## Car-specific safety domains
- Pedestrians, cyclists, animals and vulnerable road users.
- Braking, steering, tire, suspension and stability faults.
- Collision and unintended movement.
- Battery thermal/electrical hazards and charging faults.
- Rain, glare, fog, road debris and sensor occlusion.
- GNSS spoofing, network loss and stale remote commands.
- Driver override and a validated minimal-risk condition.

## Rule
Do not begin with autonomous road control. Start with recorded/synthetic data, offline perception, simulation and warning-only proposals. Any future vehicle control requires a separate safety case, independent safeguards and authorization.
