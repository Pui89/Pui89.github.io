Why PUI89 uses this workflow

FreeCut can support repeatable communication of research and concept work while keeping original footage and project files under the operator's control. It is a production aid, not evidence that a product has been built, tested or validated.

Editing & motion

Multi-track video, audio, text, images, shapes, masks, Lottie and compound clips; keyframes, transitions, color tools, LUTs and chroma key.

Local AI & analysis

Project README lists on-device transcription (Parakeet with Whisper fallback), local vision-language captioning providers, Kokoro text-to-speech, MusicGen generation and scene analysis. Actual model availability and performance depend on setup and hardware.

Export & delivery

In-browser export supports MP4, WebM, MOV and MKV, with codec availability determined by browser encoders and the selected export path. Always verify the exported file before publishing.

Local project storage

FreeCut documents a workspace folder with project files, linked-media metadata, thumbnails, waveforms, transcripts, generated assets and caches. Choose a dedicated local workspace and maintain your own backup.

Recommended operator workflow

  1. Open FreeCut from its official website in a current Chrome or Edge browser.
  2. Create a dedicated workspace folder on a local drive with sufficient free space; keep source media in a known location.
  3. Import only material you have rights to use. Prefer licensed, original or synthetic assets; record source and permission in the project notes.
  4. Edit a short test project first. Check playback, audio sync, captions, transitions, keyframes and export on your own machine.
  5. For AI features, choose explicitly local/on-device providers. Review any model source and first-run model downloads before allowing them; do not enable remote providers for confidential work.
  6. Export a short sample, verify codec/container playback and inspect the file metadata before producing a full-length video.
  7. Back up the workspace and final exports locally. Remove temporary media only after confirming the backup.

Compatibility & limitations

Browser

FreeCut's README recommends Chrome or Edge 113+ and depends on WebGPU, WebCodecs, OPFS and the File System Access API for its full workflow. Feature support varies by browser, operating system and GPU driver.

PUI89 workstation

The Acer Nitro AN515-57 configuration previously identified (Core i7-11800H, 16 GB RAM, RTX 3050 Laptop GPU) is a reasonable candidate for a small trial project, not a verified compatibility result. Check browser WebGPU status, available VRAM, thermals, disk space and export speed. Start with 1080p proxies or short clips.

Do not assume every listed codec is available on every device. FreeCut performs capability checks; the browser's actual encoder support determines export options. Local AI can still require model downloads, memory and substantial GPU/CPU resources.
