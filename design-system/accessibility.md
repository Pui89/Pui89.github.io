# Accessibility Standard

Target WCAG 2.2 AA for public websites and digital interfaces.

- Maintain at least 4.5:1 contrast for normal text and 3:1 for large text and meaningful UI graphics.
- Never use Electric Cyan as small text on white; pair it with Deep Navy or another verified dark foreground.
- All functionality must be keyboard accessible with visible focus indicators and logical focus order.
- Use semantic headings, landmarks, buttons, links, labels and table headers.
- Provide meaningful alt text for informative images; decorative images use empty alt text.
- Do not communicate status using colour alone. Include text such as “Concept” or “Bench-tested”.
- Respect reduced-motion preferences; avoid flashing and unnecessary animation.
- Ensure controls have accessible names, adequate target sizes and clear error messages.
- Test responsive zoom/reflow, keyboard-only operation and screen-reader reading order.
- Thai content must use appropriate line height and must not clip tone marks or vowels.
- Captions and transcripts are required for meaningful audio/video content.
