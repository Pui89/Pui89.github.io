## Consistency rules
1. Use the PUI89 master logo and shared type/spacing system on every project.
2. Use project accent colours for highlights, diagrams, badges and small graphic elements—not as an excuse for unrelated layouts.
3. Keep neutral backgrounds and readable body text.
4. Use the same status vocabulary everywhere: Concept → Designed → Simulated → Bench-tested → Field-tested → Certified (only when evidence justifies it).
5. Do not colour-code status solely by colour; include text labels.
6. Every project page and README should identify its purpose, intended users, maturity, evidence, limitations, next milestone and collaboration/support route.
