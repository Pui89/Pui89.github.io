# PUI89 Company-wide Design Quality Checklist

Use this checklist for every future design, website page, README, diagram, software UI and physical product concept.

## Brand and consistency
- [ ] Approved PUI89 master logo, proportions and clear space.
- [ ] Deep Navy + Electric Cyan master identity retained.
- [ ] Correct project accent identity applied.
- [ ] Shared typography, spacing, components and status vocabulary used.
- [ ] No unrelated or competing corporate identity.

## Content and evidence
- [ ] Professional, internationally understandable presentation.
- [ ] English/Thai versions are equivalent and current.
- [ ] Concepts, simulations, prototypes, tests and certifications clearly distinguished.
- [ ] Every technical/commercial claim has supporting evidence or is labelled a target.
- [ ] No obsolete, duplicated, contradictory or placeholder content.
- [ ] Images are relevant, correctly captioned and not presented as real hardware if conceptual.
- [ ] QR codes resolve to the intended canonical destinations and are scan-tested.

## Digital quality
- [ ] Mobile, tablet and desktop layouts work.
- [ ] Keyboard navigation, focus, semantic structure and alt text checked.
- [ ] Contrast and reduced-motion needs checked.
- [ ] Links, metadata, language links and page navigation verified.
- [ ] No unnecessary external dependencies or paid services.

## Product and robotics
- [ ] User needs, operating environment and non-use cases documented.
- [ ] Manufacturability, serviceability, repairability and maintenance considered.
- [ ] Materials, weight, power, stability and safety assumptions documented.
- [ ] Water/fire/environmental ratings not claimed without appropriate test evidence.
- [ ] Manual override, safe state and emergency stop considered where relevant.
- [ ] Prototype status and test evidence accurately reported.

## Delivery governance
- [ ] Reuse shared components rather than duplicating code.
- [ ] Change is focused, reviewable and reversible.
- [ ] Existing user content and repository protections preserved.
- [ ] Relevant checks run and results recorded.
- [ ] No paid service, billing change, physical actuation or unapproved publication.
