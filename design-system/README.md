# PUI89 Global Design System

**Status:** v1.0 foundation / implementation standard  
**Applies to:** all current and future PUI89 projects, products, software, robotics concepts, research materials and public channels.  
**Master brand:** PUI89. Project identities are sub-identities, never separate unrelated brands.

## Purpose
Create one recognisable, accessible, bilingual and maintainable visual system. The system must work for a small independent R&D initiative today and scale to products, partners and a future registered company without implying that PUI89 is already incorporated.

## Non-negotiable principles
- PUI89 master identity remains Deep Navy + Electric Cyan with the established bold N mark and cut ends. Do not replace it with an unrelated brand.
- Project accent colours distinguish domains while shared typography, layout, logo placement, components and evidence labels preserve family resemblance.
- English and Thai pages must be functionally equivalent and visually consistent.
- Design must be responsive, accessible, maintainable and lightweight.
- Never depict a concept as a built or validated product. Label concepts, simulations, prototypes and tested capabilities accurately.
- Do not claim ratings, certifications, performance, safety, manufacturing readiness or commercial availability without evidence.
- Prefer existing assets and dependency-free CSS. No paid tools, subscriptions, hosted services or unnecessary packages.

## Adoption sequence
Foundation → shared website components → English/Thai page rollout → README and technical-document templates → product and robotics design standards → commercial collateral. Roll out incrementally through focused review pull requests; do not perform risky mass rewrites.

## Versioning
Update this system when a shared rule changes. Record rationale and affected projects. Project-specific exceptions must be documented rather than silently diverging.
