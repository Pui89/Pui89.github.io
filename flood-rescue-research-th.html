AI กู้ภัยน้ำท่วม: งานวิจัยด้านการรับรู้และภูมิประเทศ

ภาพรวมทางเทคนิคของการจัดการหลักฐานเพื่อทำความเข้าใจสถานการณ์น้ำท่วมของ PUI89 ครอบคลุมบริบทภูมิประเทศ ข้อมูลวิดีโอที่เปลี่ยนแปลงตามเวลา คุณภาพ segmentation และความไม่แน่นอน เป็นการพัฒนาซอฟต์แวร์และการจำลองเป็นหลัก

สถานะการพัฒนาและขอบเขตความปลอดภัย: เนื้อหาด้านล่างอธิบายโค้ดวิจัย วิธีการที่อยู่ระหว่างพิจารณา และ pull request ฉบับร่าง ไม่ใช่บริการเตือนภัยน้ำท่วมที่เปิดใช้งานจริง หุ่นยนต์กู้ภัยที่ผ่านการรับรอง เครื่องมือวัดความลึกน้ำที่สอบเทียบแล้ว หรือหลักฐานว่าเส้นทางปลอดภัย งานบางส่วนยังอยู่ระหว่างตรวจสอบ ต้องตรวจสอบผลทดสอบและการตรวจสอบภาคสนามจากบันทึกที่เชื่อมโยง
01 · LIDAR / ภูมิประเทศ

บริบทภูมิประเทศและตัวบ่งชี้การไหล

โครงงานวิจัยตรวจสอบข้อมูลระดับความสูงแบบกริด การจัดการ NoData ความลาดชันเฉพาะพื้นที่ ทิศทางการไหลแบบ D8 และการสะสมการไหล ข้อมูลเหล่านี้ช่วยจัดระบบหลักฐานภูมิประเทศและระบุพื้นที่ที่ต้องตรวจสอบทางอุทกวิทยาเพิ่มเติม แต่ไม่สามารถทำนายความลึกน้ำ ความเร็วกระแสน้ำ หรือเส้นทางกู้ภัยที่ปลอดภัยได้ด้วยตัวเอง

สถานะ: โค้ดต้นแบบอยู่บน branch สำหรับตรวจสอบ ยังไม่มีหลักฐานยืนยันการอ่าน LiDAR จริงหรือการตรวจสอบทางอุทกวิทยา

ดู branch งานวิจัย LiDAR ↗
02 · VIDEO / หลักฐานตามเวลา

การติดตามวิดีโอและข้อมูลที่เปลี่ยนแปลง

ระบบบันทึกหลักฐานตามเวลาสามารถเก็บการอ้างอิงเฟรม รหัสวัตถุที่ได้รับ ช่องว่างของเฟรม และความขัดแย้งของป้ายกำกับเพื่อให้มนุษย์ตรวจสอบ เป็นพื้นฐานสำหรับประเมินความต่อเนื่อง ไม่ใช่ระบบถอดรหัสวิดีโอ ตัวตรวจจับวัตถุ หรือตัวติดตามที่พร้อมใช้งานจริง

สถานะ: โครงสร้างซอฟต์แวร์อยู่บน branch สำหรับตรวจสอบ ยังไม่มีการอ้างผลประสิทธิภาพกับวิดีโอน้ำท่วมจริง

ดู branch งานวิจัยวิดีโอ ↗
03 · SEGMENTATION / การประเมินผล

วัดคุณภาพการแบ่งส่วนภาพ

โครงสร้าง benchmark กำหนดเมตริกจาก confusion matrix ได้แก่ pixel accuracy, IoU รายคลาส, Dice, precision และ recall รวมถึงการวินิจฉัย identity switch และ track fragmentation จากข้อมูลจับคู่ที่ป้อนให้ เมตริกต้องใช้ข้อมูลอ้างอิงที่มีป้ายกำกับเหมาะสมและควรแปลผลแยกตามคลาสและสถานการณ์

สถานะ: โค้ดประเมินผลและแนวทางอยู่ใน pull request ฉบับร่าง ยังไม่อ้างว่ามีการรันทดสอบแล้ว

04 · DEPTH / โมเดลที่อยู่ระหว่างพิจารณา

ความลึกสัมพัทธ์ไม่ใช่ความลึกน้ำท่วม

Depth Anything V2 Small ถูกบันทึกเป็นโมเดลที่อยู่ระหว่างพิจารณาสำหรับสัญญาณความลึกสัมพัทธ์ของฉาก ความลึกสัมพัทธ์จากภาพเดียวไม่ได้แปลว่าเป็นระยะทางจริง ระดับผิวน้ำ หรือความลึกน้ำท่วมที่สอบเทียบแล้ว การใช้งานต้องมีการสอบเทียบเฉพาะโดเมน ค่าการวัดอ้างอิง และการประเมินความคลาดเคลื่อน

สถานะ: บันทึกโมเดลที่อยู่ระหว่างพิจารณาเพื่อพิจารณา ยังไม่ได้ดาวน์โหลด weights และไม่ได้อ้างว่ามีการเชื่อมต่อ inference

ตรวจสอบ PR โมเดล depth ↗

หลักการประเมินผล

  • เก็บแหล่งที่มา เวลา พิกัดหรือการอ้างอิงเฟรม ที่มาของป้ายกำกับ และความไม่แน่นอนควบคู่กับข้อมูลสังเกต
  • รายงานข้อมูลเซนเซอร์ที่ขาดหาย ล้าสมัย มีสัญญาณรบกวน หรือขัดแย้งกัน แทนการเติมข้อมูลโดยไม่แจ้ง
  • แยกค่าที่วัดได้ออกจากค่าประมาณสัมพัทธ์และการตีความที่เสนอ
  • ใช้ข้อมูลทดสอบที่แยกตามสถานการณ์ รายงานความไม่สมดุลของคลาสและกรณีล้มเหลว ไม่รายงานเฉพาะคะแนนรวม
  • ให้มนุษย์ตรวจสอบการตัดสินใจด้านกู้ภัย ห้ามส่งคำสั่งหุ่นยนต์จริงจากหน้านี้หรือโครงสร้างซอฟต์แวร์วิจัย

หลักฐานแบบใดจึงจะแข็งแรงขึ้น?

ชุดข้อมูลที่มีเวอร์ชันและที่มาถูกต้องตามกฎหมาย คำอธิบายประกอบที่ผ่านการตรวจสอบ คำสั่งทดสอบและผลที่ทำซ้ำได้ การสอบเทียบกับการวัดอิสระ การทดสอบความทนทานต่อฝน แสงสะท้อน การบดบัง ภาพกลางคืน เซนเซอร์ขาดหาย และข้อมูลขัดแย้ง รวมถึงการศึกษาใน simulation และภาคสนามภายใต้การกำกับดูแล จนกว่าจะมีบันทึกดังกล่าว ความสามารถยังถือว่าไม่ได้รับการยืนยัน
