STATUS DEFINITIONS

Research is not implementation

Use the same four labels across the radar. Status applies to PUI89's own work—not to the maturity of the external technology.

ResearchingSource identified; relevance and limitations being understood.
EvaluatingFit, licence, provenance, compute and risk review documented.
TestingA bounded PUI89 experiment exists with reproducible results.
ImplementedIntegrated code exists and is traceable to repository evidence.

Current baseline — 13 November 2026: All five entries are marked Researching. No entry is represented as tested or implemented in PUI89. This page itself is a published information page, not evidence of adoption of the listed technologies.

MONTHLY GOVERNANCE

One review, not another daily task

Review cadence

Review this shared page once per month. Add an item only when a credible source, publication date, PUI89 connection and evidence status are available.

Next planned review: December 2026

Adoption gate

Before any PUI89 test or adoption, check open-source licence and provenance, non-Chinese origin preference, hardware fit, memory, latency, power, privacy, safety and zero-cost constraints. No downloads, installations, paid APIs or subscriptions are authorised by listing an item here.

The radar does not create seven duplicated trend pages. Each product remains responsible for its own requirements and validation evidence; shared technology assessment lives here.
