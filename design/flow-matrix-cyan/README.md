# PUI89 Flow Matrix — Deep Blue + Bright Cyan

Three original geometric SVG directions for the PUI89 identity.

## Palette

- Deep blue: `#071B4A`
- Royal blue: `#123D91`
- Bright cyan: `#00BFEF`
- Light cyan: `#42E8FF`

## Concepts

1. **Continuous Flow** — a clean, memorable geometric N formed by two strong pillars and one uninterrupted diagonal ribbon. Recommended lead direction for a scalable company identity.
2. **Node Matrix** — a more technical, connected-systems expression with visible data/flow nodes. Stronger for AI engineering and platform messaging.
3. **Interlock** — a heavier, more industrial mark with an interlocking diagonal bridge. Stronger for robotics and hardware-facing materials.

All three are abstract geometric marks. None uses a roof, house, building or shield silhouette.

## Design intent

- N is an abstract flow/matrix monogram, not an architectural outline.
- PUI89 is set directly underneath in a bold geometric sans-serif style.
- SVGs use editable vector paths and text, with no raster artwork or external assets.
- The wordmark currently uses an Arial/Helvetica fallback stack; final font outlining can be done after selecting a concept.

## Review

Open the three SVG files in a browser or vector editor and compare at both large and small sizes. Select one direction before replacing the existing live brand assets.
