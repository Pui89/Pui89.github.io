PUI89 · คลัง Open Source และวิศวกรรม

แหล่งทรัพยากร Open Source, Agentic AI และวิศวกรรมขั้นสูง

คัดเลือกทรัพยากรเริ่มต้นสำหรับ AI Car, AI Motorcycle, หุ่นยนต์ ระบบรับรู้ การจำลอง และวิศวกรรม

หน้าหลัก PUI89 · English

การตรวจสอบทรัพยากรและใบอนุญาต: ใบอนุญาตซอฟต์แวร์ไม่ได้ให้สิทธิ์ใช้โมเดล ชุดข้อมูล บริการโฮสต์ หรือการใช้งานเชิงพาณิชย์โดยอัตโนมัติ ควรตรวจสอบใบอนุญาต แหล่งที่มา ความต้องการฮาร์ดแวร์ การจัดการข้อมูล และเงื่อนไขของผู้ให้บริการแต่ละรายการก่อนนำมาใช้ รายการนี้ไม่รวมตระกูลโมเดลจากจีนตามแนวทางจัดหาของ PUI89

1 · ระบบ AI ในเครื่อง

  • Ollama — รันโมเดลในเครื่อง; ซอฟต์แวร์ MIT แต่ใบอนุญาตโมเดลแยกกัน
  • llama.cpp — ประมวลผลในเครื่อง; MIT
  • Transformers — ไลบรารีโมเดล; Apache-2.0

พิจารณา Google Gemma, Microsoft Phi, Meta Llama และ Mistral โดยตรวจเงื่อนไขแต่ละรุ่น ใบอนุญาตน้ำหนักโมเดลต่างกัน

2 · Agentic AI

  • PydanticAI — Agent Python แบบกำหนดชนิดข้อมูล; MIT
  • LangGraph — จัดการเวิร์กโฟลว์; บริการโฮสต์คิดแยก
  • smolagents — Agent ขนาดเล็ก; Apache-2.0
  • CrewAI — เวิร์กโฟลว์หลาย Agent; ตรวจส่วนโฮสต์/องค์กร
  • OpenAI Agents SDK — SDK แต่ค่าเรียกโมเดล/API อาจมีค่าใช้จ่าย

Agent ของ PUI89 ใช้ช่วยวิเคราะห์และเสนอคำแนะนำเท่านั้น ห้ามควบคุมรถ

3 · AI และ Computer Vision

  • PyTorch
  • OpenCV — รุ่น 4.5.0+ Apache-2.0
  • scikit-learn
  • NumPy · pandas · Jupyter

4 · หุ่นยนต์และจำลองยานยนต์

  • ROS 2 Jazzy
  • Gazebo
  • CARLA — จำลองรถยนต์
  • SUMO — จำลองการจราจร
  • MuJoCo — จำลองฟิสิกส์ ตรวจใบอนุญาตแต่ละรุ่น

ใช้เพื่อจำลองเท่านั้น ไม่ใช่หลักฐานความปลอดภัยหรือสมรรถนะรถจริง

5 · CAD, อิเล็กทรอนิกส์ และแผนที่

  • OpenSCAD — GPL
  • KiCad — GPL
  • QGIS — GPL
  • OpenStreetMap — ODbL และต้องให้เครดิต

6 · ข้อมูล การทดสอบ และความปลอดภัย

  • CVAT — ตรวจเงื่อนไขรุ่นและการติดตั้ง
  • FiftyOne
  • pytest · pre-commit
  • OpenSSF Scorecard
  • GitHub Actions

เงื่อนไขนำมาใช้ใน PUI89

  1. ตรวจรุ่น ใบอนุญาต แหล่งที่มา และสิทธิ์ใช้เชิงพาณิชย์
  2. ตรวจ API โฮสต์ Telemetry เงื่อนไขผู้ให้บริการและการจัดการข้อมูล
  3. ตรวจ RAM พื้นที่ดิสก์ และกำลังประมวลผลก่อนติดตั้ง/ดาวน์โหลด
  4. ใช้ของเดิมและกฎพื้นฐานก่อน ทดลองออฟไลน์ขนาดเล็ก
  5. Agent เสนอคำแนะนำเท่านั้น ห้ามสั่งพวงมาลัย คันเร่ง เบรก ระบบขับเคลื่อน ECU/CAN หรือควบคุมรถทางไกล
  6. แยกสถานะ เสนอ/พัฒนาแล้ว/ทดสอบจำลอง/ทดสอบอุปกรณ์/ทดสอบภาคสนาม/ตรวจสอบอิสระ

ลำดับระบบรถ: ข้อมูลเซนเซอร์สังเคราะห์ → ตรวจหลักฐาน → PUI89 AI Core กลาง → วิเคราะห์สถานะและอันตราย → Agent ให้คำแนะนำ → จำลองซ้ำ → ทดสอบความผิดพลาดและความปลอดภัย → รายงานหลักฐาน
