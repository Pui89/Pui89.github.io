PUI89 adoption gate

  1. Verify exact version, licence, model/data provenance and commercial terms.
  2. Check for hosted APIs, telemetry, provider terms and data handling.
  3. Check local RAM, disk and compute before installing/downloading.
  4. Prefer existing dependencies and deterministic baselines; test offline first.
  5. Agents may analyze and make proposals only. No steering, throttle, brake, propulsion, ECU/CAN or remote control.
  6. Label proposed, implemented, simulation-tested, bench-tested, field-tested and independently validated separately.

Vehicle pipeline: synthetic sensor data → evidence validation → shared PUI89 AI Core → state/hazard reasoning → advisory agent → simulation replay → failure/security tests → evidence report.
