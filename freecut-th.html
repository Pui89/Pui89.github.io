ระบบผลิตวิดีโอภายในเครื่อง

แนวทางตัดต่อวิดีโอผ่าน Web Browser สำหรับสร้างวิดีโอสาธิตงานวิจัย อธิบายแนวคิดผลิตภัณฑ์ และนำเสนอวิศวกรรมของ PUI89 โดยไม่ต้องติดตั้งโปรแกรมตัดต่อบนเครื่อง และไม่ต้องอัปโหลดไฟล์ต้นฉบับไปยังบริการตัดต่อบน Cloud

ข้อควรทราบด้านความเป็นส่วนตัว: เอกสารของ FreeCut ระบุว่าการตัดต่อ วิเคราะห์ สร้าง AI และ Export ทำงานใน Browser และจัดเก็บโปรเจกต์/สื่อไว้ใน Workspace ที่ผู้ใช้เลือก หน้านี้เป็นการแนะนำเครื่องมือและกำหนด Workflow ของ PUI89 ไม่ใช่ผลการตรวจสอบความปลอดภัยโดยอิสระ ก่อนใช้ข้อมูลลับควรตรวจสอบเวอร์ชันที่ใช้งาน ผู้ให้บริการ AI ที่เปิดใช้ การดาวน์โหลดโมเดล สิทธิ์ของ Browser และ Network Activity ไม่ควรถือว่าทุก Extension โมเดล หรือการเชื่อมต่อเสริมทำงานแบบ Offline ทั้งหมด

เหตุผลที่ PUI89 เลือก Workflow นี้

FreeCut ช่วยผลิตสื่ออธิบายงานวิจัยและแนวคิดผลิตภัณฑ์ โดยให้ผู้ใช้ควบคุมไฟล์ต้นฉบับและโปรเจกต์ไว้ในเครื่อง ทั้งนี้เป็นเครื่องมือช่วยสื่อสาร ไม่ใช่หลักฐานว่าผลิตภัณฑ์ถูกสร้าง ทดสอบ หรือผ่านการตรวจสอบแล้ว

ตัดต่อและภาพเคลื่อนไหว

Multi-track รองรับวิดีโอ เสียง ข้อความ รูปภาพ รูปร่าง Mask, Lottie และ Compound Clips รวมถึง Keyframes, Transitions, เครื่องมือปรับสี LUT และ Chroma Key

Local AI และการวิเคราะห์

README ระบุการถอดเสียงภายในเครื่อง (Parakeet และ Whisper fallback), การสร้างคำบรรยายด้วย Local Vision-Language Providers, Kokoro Text-to-Speech, MusicGen และ Scene Analysis ประสิทธิภาพและความพร้อมใช้งานขึ้นกับโมเดล การตั้งค่า และฮาร์ดแวร์

Export และส่งมอบงาน

รองรับการ Export ภายใน Browser เป็น MP4, WebM, MOV และ MKV โดย Codec ที่ใช้ได้ขึ้นกับ Encoder ของ Browser และเส้นทาง Export ควรตรวจสอบไฟล์ที่ Export แล้วก่อนเผยแพร่ทุกครั้ง

จัดเก็บโปรเจกต์ในเครื่อง

เอกสาร FreeCut ระบุการจัดเก็บ Workspace Folder ซึ่งมีไฟล์โปรเจกต์ Metadata ของสื่อ Thumbnail, Waveform, Transcript, Generated Assets และ Cache ควรเลือกโฟลเดอร์เฉพาะและสำรองข้อมูลเอง

Workflow ที่แนะนำ

  1. เปิด FreeCut จากเว็บไซต์ทางการด้วย Chrome หรือ Edge เวอร์ชันปัจจุบัน
  2. สร้าง Workspace Folder เฉพาะบนไดรฟ์ภายในเครื่องที่มีพื้นที่เพียงพอ และจัดเก็บไฟล์ต้นฉบับในตำแหน่งที่ทราบแน่ชัด
  3. นำเข้าเฉพาะสื่อที่มีสิทธิ์ใช้งาน ควรเลือกสื่อที่สร้างเอง ได้รับอนุญาต หรือเป็น Synthetic Data พร้อมบันทึกแหล่งที่มาและสิทธิ์
  4. เริ่มจากโปรเจกต์ทดลองขนาดเล็ก ตรวจสอบ Playback, Audio Sync, Subtitle, Transition, Keyframe และ Export บนเครื่องจริง
  5. สำหรับ AI ให้เลือกผู้ให้บริการที่ประมวลผลภายในเครื่องอย่างชัดเจน ตรวจสอบแหล่งที่มาของโมเดลและการดาวน์โหลดโมเดลครั้งแรกก่อนอนุญาต ห้ามเปิดใช้ Remote Provider กับข้อมูลงานลับ
  6. Export ตัวอย่างสั้น ๆ ตรวจสอบการเล่นไฟล์ Codec/Container และ Metadata ก่อนทำวิดีโอฉบับเต็ม
  7. สำรอง Workspace และไฟล์ Export ไว้ในเครื่องก่อนลบไฟล์ชั่วคราว

ความเข้ากันได้และข้อจำกัด

Browser

README ของ FreeCut แนะนำ Chrome หรือ Edge 113+ และใช้ WebGPU, WebCodecs, OPFS และ File System Access API สำหรับ Workflow เต็มรูปแบบ การรองรับจริงขึ้นกับ Browser, ระบบปฏิบัติการ และ GPU Driver

เครื่อง PUI89

เครื่อง Acer Nitro AN515-57 ที่เคยระบุไว้ (Core i7-11800H, RAM 16 GB, RTX 3050 Laptop GPU) เป็นเครื่องที่เหมาะสำหรับเริ่มทดลองโปรเจกต์ขนาดเล็ก แต่ยังไม่ใช่ผลยืนยันความเข้ากันได้ ควรตรวจสอบ WebGPU, VRAM, อุณหภูมิ พื้นที่ดิสก์ และความเร็ว Export เริ่มจากวิดีโอสั้นหรือ Proxy 1080p

อย่าสมมติว่าอุปกรณ์ทุกเครื่องรองรับ Codec ทุกชนิด FreeCut จะตรวจสอบความสามารถที่มีจริงของ Encoder ใน Browser เป็นตัวกำหนดตัวเลือก Export ส่วน Local AI อาจยังต้องดาวน์โหลดโมเดลและใช้หน่วยความจำหรือทรัพยากร GPU/CPU สูง

สถานะการนำไปใช้ใน PUI89: เพิ่มเอกสาร Workflow บนเว็บไซต์แล้ว FreeCut เป็นโครงการ Third-party อิสระ PUI89 ยังไม่ได้ Fork แก้ไข Host หรือตรวจสอบ Source Code ของ FreeCut หน้านี้ไม่ได้ติดตั้ง ดาวน์โหลด ซื้อ หรือ Deploy โปรแกรมใด ๆ
