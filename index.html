One shared engineering foundation

PUI89 is being developed as a common AI-software foundation supporting seven specialised project areas. The shared-core work is being introduced and reviewed incrementally; this section describes the architecture direction, not a claim that every component is already integrated or validated.

01 / STATE & UNCERTAINTY

Know what the system knows

Track observation source, timestamp, confidence, calibration status, stale inputs, and conflicting evidence. Represent the changing world state explicitly, propagate uncertainty into task plans, and request human review when evidence is incomplete or unreliable.

Software contract under review
02 / AUTOMATED CHECKS

Make failures visible

Use repeatable Python checks and structured test reports to record failures, environment details, and evidence. Passing software tests does not establish field performance or robot safety.

Development stage: incremental implementation
03 / SAFE TASK FLOW

Separate proposals from actions

Keep perception, world-state tracking, task planning, safety monitoring, and physical actuation as distinct interfaces. Simulation and human review come before any hardware integration; no physical capability is implied.

Simulation-first roadmap
04 / RESEARCH ROADMAP

Agentic AI, VLM and VLA — staged evaluation

The technology roadmap explores agentic task workflows, vision-language models (VLMs), and vision-language-action (VLA) interfaces through staged software evaluation and simulation. Each capability advances through defined engineering checks, evidence review and human approval before any real-world integration is considered.
